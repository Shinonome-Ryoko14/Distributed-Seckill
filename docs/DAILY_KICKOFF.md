# 每日开工口令

> 用法：每天新开对话，把下面整段作为第一句发给 AI。

---

开始今天的工作。严格执行 `harness_project.md` §17：

1. 全文读 `harness_project.md` 进入状态（牢记 §3 硬约束、§10–16 规范）；
2. 读 `docs/PROGRESS.md`：先看顶部「当前状态」（最高权重），再按「时间优先（最近 3 天/5 条）+ 改动量（L 兜底）」读任务日志；
3. 读 `docs/DECISIONS.md` 中与当前里程碑相关的 ADR，不全文；
4. 用 ≤5 行复述「当前里程碑 / 上次做到哪 / 今天建议做什么 / 阻塞」，等我确认后再开工。

收工前请按 §18：更新 `docs/PROGRESS.md` 顶部快照与任务日志（含影响 L/M/S + 涉及文件），有新决策写 ADR，并提醒我 commit（不要擅自提交）。
